# Practicum_projects

Проекты по анализу данных, выполненные во время обучения на курсе «Аналитик данных».

| Проект | Описание | Инструменты |
|---|---|---|
| [Рынок стартапов](startup_market) | Рекомендация инвестиционной компании: в какой сегмент рынка и тип финансирования вкладываться в 2015 году | pandas, NumPy, matplotlib |
| [Общепит Москвы](moscow_catering) | Исследовательский анализ рынка заведений общественного питания Москвы: категории, рейтинги, средний чек | pandas, matplotlib, seaborn, phik |
| [Рынок видеоигр](games_research) | Предобработка данных о продажах игр, категоризация оценок, топ платформ | pandas |

## Структура репозитория
Каждый проект лежит в отдельной папке:
- `README.md` — описание проекта и выводы;
- `*.ipynb` — тетрадь Jupyter Notebook с решением.
