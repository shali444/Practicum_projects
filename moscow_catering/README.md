# Исследование заведений общественного питания в Москве

## Описание проекта
Данные о 8 400 заведениях Москвы: категория, округ, рейтинг, сетевой статус, посадочные места и средний чек. Цель — описать структуру рынка общепита и найти факторы, связанные с рейтингом и ценой, чтобы подготовить рекомендации для открытия нового заведения.

## Что сделано
- Объединены два датасета (информация о заведениях и цены), обработаны пропуски, удалены неявные дубликаты.
- Исследованы категории заведений, распределение по округам, доля сетевых заведений, посадочные места, рейтинги.
- Рассчитана корреляция рейтинга с другими признаками (коэффициент phik).
- Построен топ-15 популярных сетей, изучена связь среднего чека с удалённостью от центра.

## Выводы
- Кафе (28,3%), рестораны (24,3%) и кофейни (16,8%) вместе дают почти 70% рынка.
- Центральный округ лидирует: 26,7% всех заведений; в нём на первом месте рестораны, а доля баров заметно выше, чем по городу.
- 38% заведений сетевые; чаще всего сетевыми бывают булочные, пиццерии и кофейни.
- Рейтинги по категориям различаются слабо (от 4,05 до 4,39), сильнее всего рейтинг связан с ценовой категорией.
- Средний чек снижается по мере удаления округа от центра; самый широкий разброс цен — в Центральном и Западном округах.

## Инструменты
Python, pandas, matplotlib, seaborn, phik
