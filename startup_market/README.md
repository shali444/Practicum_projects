# Рынок стартапов: рекомендация для инвестиционной компании

## Описание проекта
Заказчик — инвестиционная компания, которая с позиции начала 2015 года выбирает, в какой сегмент рынка и в какой тип финансирования вкладываться. Данные — история финансирования компаний и возвраты средств по годам и типам финансирования.

## Что сделано
- Предобработка: дубликаты, пустые строки, строки без финансирования, типы данных, проверка дат.
- Группировка компаний по срокам и объёму финансирования, классификация сегментов на массовые, средние и нишевые.
- Анализ типичных и аномальных объёмов финансирования, выбор периода исследования.
- Динамика раундов и объёмов по годам, доля возврата средств по типам финансирования.
- Исходы компаний (покупка, IPO, закрытие) по сегментам для когорт 2005–2009.

## Выводы и рекомендация
- **Отрасль — здравоохранение.** Medical — единственный массовый сегмент, где финансирование растёт пять лет подряд (с 12 до 175 млн долл. в 2009–2014). Его стоит дополнить более крупным Health Care: доля выходов 19% при медиане 17,2%.
- **Тип финансирования — venture.** На него приходится 80% объёма инвестиций и 74% возвратов; доля возврата стабильна (~27%). Debt financing можно добавить как более стабильную часть портфеля, seed в качестве основы не рекомендуется: его доля возврата упала с 46% до 21%.
- Самая высокая доля выходов у B2B-сегментов (Enterprise Software, Web Hosting, Security — 27–30%), но они теряют долю рынка.
